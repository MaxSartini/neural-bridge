# Study Journey

Each package retains the decisive evidence that advanced the programme: the final state of a phase, the design lessons that shaped the next one, and the compact artifacts needed to audit every conclusion. Current shared code lives in `src/neural_bridge/`; historical phase scripts are not presented as the active API.

## Original VEATIC

[Original VEATIC v2 closure](original-veatic/v2-closure/README.md) established controlled future arousal event/spike ranking and showed that short causal temporal change could outperform current-only state. Its confirmed scope was event ranking; continuous specialization came later on AGAIN. It contributes historical hypotheses to later work, not fitted artifacts or an exact recipe.
