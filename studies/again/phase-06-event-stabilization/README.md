# AGAIN Phase 6: Event Stabilization

Phase 6 established a simple, prospectively declared checkpoint ensemble as a repeatable event-head stabilization method.

The controlled selection sequence ruled out an Optuna single-seed configuration and two fixed blends that did not improve robustly under fresh confirmation. That evidence narrowed the solution to independently trained checkpoints from the already validated reference recipe.

The prospectively declared reference-checkpoint average passed fresh blocked confirmation and grouped held-out-video closure. Final grouped event PR-AUC was `0.2344` versus frozen AR `0.2180` and best matched control `0.2180`: an absolute gain of `+0.0163` and a relative gain of **`+7.48%`**, positive in `15/15` fold-groups with every declared gate passed.
