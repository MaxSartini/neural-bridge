# AGAIN Phase 5/5.5: Learned Bridge and Event Head

This package preserves the full scientific transition from fixed representations to a validated learned event head.

The sequence matters:

1. An eval-mode rescore corrected the initial learned-head evaluation.
2. A frozen-AR residual bridge established useful learned signal. On grouped spike ranking it reached PR-AUC `0.2383`, `+39.95%` over direct AR-plus-raw and `+38.85%` over the Phase 4 bridge.
3. Continuous ranking improved, but exact-value forecasting remained unproven.
4. The first redesigned event target failed against matched controls.
5. Causal temporal heads changed the outcome. `short_temporal_conv_residual` passed blocked confirmation at PR-AUC `0.2671` versus frozen AR `0.2602`, then grouped held-out-video compatibility at `0.2314` versus AR `0.2175`, positive in `50/50` fold-seeds.
6. The final `420`-row assembly combines the already completed blocked and grouped evidence without rerunning models. Its corrected verdict applies the residual-appropriate null while retaining the original failed wording for auditability.

`evidence/` contains the current compact CSV/JSON/report packages for each transition. Two fitted PCA row-index exports are intentionally omitted because the registered external Phase 5 collection owns those heavy derived artifacts. The canonical engine, evidence verifier, and checksum-locked checkpoint replay replace the 22 phase-coupled script copies.

The older all-phase review and historical-ladder bundles are redundant snapshots, not authorities; they remain untouched until final cutover approval.
